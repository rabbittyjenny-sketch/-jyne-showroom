# iDEAS365 · เว็บหมู่เกาะ + หลังบ้าน

เว็บโปรไฟล์และผลงานของเจนจิรา ใจสิน ทำเป็นแผนที่หมู่เกาะ ทุกอย่างบนหน้าเว็บเพิ่ม แก้ และซ่อนได้จากหลังบ้าน โดยไม่ต้องแก้โค้ด

## โครงสร้าง

```
แม่แบบเกาะ → เกาะ → เมนูย่อย (ปุ่มบนเกาะ) → ผลงาน
                         └ ประเภทผลงาน (กำหนดช่องข้อมูลเองในหลังบ้าน)
การจัดกลุ่ม: หมวด (1 ต่อผลงาน, ซ้อน 2 ชั้น) · แท็ก (หลายอัน, อยู่ในกลุ่ม) · เส้นทางสมัครงาน (เลือก + เรียง)
```

- **สร้างเกาะ:** เลือกแม่แบบ → ได้ฟีเจอร์ตั้งต้น → เปิด/ปิดเพิ่มเฉพาะเกาะนั้นได้ (วิธีเดียวกับการสร้างงานใน EMS)
- **ประเภทผลงาน:** ช่องข้อมูลเก็บในฐานข้อมูล ประเภทใหม่จึงไม่ต้องแก้โค้ด
- **อัปหลายชิ้น:** ครั้งละไม่เกิน 10 ชิ้น และทั้งชุดต้องเป็นหมวดเดียวกัน ฐานข้อมูลบังคับกฎนี้ซ้ำอีกชั้น
- **เส้นทางสมัครงาน:** `/r/ชื่อเส้นทาง` เส้นทางหนึ่งมีลิงก์ย่อยได้ หัวเรื่องต่างกัน แต่เนื้อหาเดียวกัน (เช่น `/r/assistant`, `/r/restaurant`)
- **เกาะพาไปเว็บอื่น:** Academy → Creatr365 และ รับวางระบบ → iDEAS365-web ขึ้นหน้าแนะนำสั้นๆ แล้วพาไปต่อเอง

| หน้า | ลิงก์ |
| --- | --- |
| แผนที่หลัก | `/` |
| เกาะ | `/i/<เกาะ>` |
| เมนูย่อย | `/i/<เกาะ>/<เมนู>` |
| เส้นทางสมัครงาน | `/r/<เส้นทาง>` |
| หลังบ้าน (ไม่มีลิงก์จากหน้าเว็บ) | `/backoffice/login` |

## ฐานข้อมูล

ใช้ฐานกลางใน Supabase ของ Creatr365 ตารางทั้งหมดขึ้นต้นด้วย `i365_` และ**ไม่แตะตารางของ Creatr365** การอ่านบทความและเทมเพลตของ Creatr365 ทำผ่านสิทธิ์อ่านสาธารณะที่มีอยู่แล้ว

> ✅ **รันครบแล้วบน Supabase ของ Creatr365 (30 ต.ค. 2026)** ทั้ง 3 ข้อด้านล่าง + ไฟล์แก้ search_path และตั้ง rabbitty.jenny@gmail.com เป็น owner แล้ว ไม่ต้องรันซ้ำ รายการนี้เก็บไว้สำหรับกรณีย้ายไปฐานใหม่

1. รัน `supabase/migrations/20261030120000_i365_schema.sql` (สร้างตาราง, สิทธิ์, ที่เก็บไฟล์ `i365-media`)
2. รัน `supabase/migrations/20261030120100_i365_seed.sql` (เกาะ เมนูย่อย ประเภท แท็ก เส้นทาง และคลิปเดิม 16 อัน) รันซ้ำได้ ไม่ทับของที่แก้ไว้
3. รัน `supabase/migrations/20261030120200_i365_fix_search_path.sql`
4. แก้อีเมลใน `docs/first-admin.sql` แล้วรัน เพื่อตั้งตัวเองเป็นผู้ดูแล รายชื่อนี้แยกจากผู้ดูแล Creatr365
5. รัน `supabase/migrations/20261030130000_i365_import_legacy.sql` (เนื้อหาจากเว็บเดิม: โปรไฟล์ ประวัติงาน กรณีศึกษา รูป เครื่องมือ QR LINE) — ✅ รันแล้ว 30 ต.ค. 2026
6. รัน `supabase/migrations/20261030140000_i365_island_theme.sql` (สีประจำเกาะจากหน้าเดิม + ปุ่ม BACK + รูปแบบแสดงเต็ม) — ✅ รันแล้ว 30 ต.ค. 2026

ข้อมูลตั้งต้นอยู่ที่ `seed/seed.json` ที่เดียว ถ้าแก้ไฟล์นี้ ให้รัน `npm run seed:sql` เพื่อสร้างไฟล์ seed ใหม่

## ติดตั้งและรัน

```bash
npm install
cp .env.example .env   # ใส่ค่าเดียวกับ Creatr365
npm run dev            # เปิด http://localhost:8080
VITE_MOCK=1 npm run dev  # ดูหน้าตาด้วยข้อมูลจำลอง ไม่ต้องต่อฐานข้อมูล (บันทึกไม่ได้)
npm run build
```

Deploy บน Vercel ได้ตามปกติ (`vercel.json` ตั้งค่าให้ทุกลิงก์เปิดผ่านแอปไว้แล้ว)

## รูปเกาะ

รายชื่อไฟล์ทั้งหมดอยู่ที่ `docs/IMAGE_NAMES.md` วางไฟล์ไว้ใน `public/` หรืออัปโหลดในหลังบ้านก็ได้ ถ้ายังไม่มีรูป เว็บจะแสดงรูปเกาะสำรองให้กดได้ไปก่อน
