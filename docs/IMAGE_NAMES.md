# ชื่อไฟล์รูปของแต่ละเกาะ

ทุกเกาะมีรูป 3 แบบ: **รูปเกาะบนแผนที่หลัก** (เป็นปุ่ม), **รูปพื้นเกาะด้านใน**, และ **รูปปุ่มแต่ละเมนูย่อย** บนเกาะนั้น

- รูปพื้นเกาะด้านใน: ขนาด 1344 × 768 (สัดส่วนเดียวกับหน้า Explore ของ Creatr365) ใช้ .webp หรือวิดีโอ .mp4 ก็ได้
- รูปปุ่ม: .png พื้นหลังโปร่งใส ตัดชิดขอบรูป
- วางไฟล์ในโฟลเดอร์ `public/` ของโปรเจกต์ตามชื่อด้านล่าง หรืออัปโหลดในหลังบ้าน (ช่องรูปของเกาะ/เมนูย่อย) ก็ได้
- ตำแหน่งปุ่ม: ตั้งในหลังบ้านเป็น % (ซ้าย / บน / กว้าง) หลังทำรูปเสร็จ เมนูที่ยังไม่ได้ตั้งตำแหน่งจะขึ้นเป็นปุ่มธรรมดาใต้แผนที่
